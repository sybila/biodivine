This project is the "biodivine workspace". It is meant to be a collection of multiple repositories that depend on each other, but are technically not a single "monorepo" because they are intended to be individually accessible. Consequently, this project is itself a git repository, but each subfolder is also its own git repository, via submodules. The dependencies between repositories are not path-based, but either commit or version based. For changes to take place, they need to be committed, pushed and then the proper commit (or version) has has to be set in the target project. Alternatively, for local development, dependencies can be temporarily changed to path-based, but this has to be reverted before the changes are published.

Note that each project most likely contains its own `AGENTS.md` file. When you start working in a specific project, always read that before anything else.
